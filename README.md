# Expense Tracker CLI

A simple command-line expense tracking application built with Python. This project allows users to add, view, and manage expenses while learning core Python concepts such as Object-Oriented Programming (OOP), file handling, JSON data storage, and modular application design.

## Features

* Add new expenses
* View all expenses
* Delete expenses
* Generate expense reports
* Store data persistently using JSON

## Technologies Used

* Python 3
* JSON
* OOP
* File Handling

## Learning Objectives

* Practice Python fundamentals
* Understand OOP design
* Work with JSON files
* Build a complete CLI application
* Learn project structure and code organization
